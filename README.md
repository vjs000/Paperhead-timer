# PAPERHEAD IGT Tracker

A Windows timer for speedrunning **PAPERHEAD v49.5**.

## Features

- In-game time (IGT) and real time (RTA) tracking
- Manual level timing controls
- Customizable keyboard shortcuts
- Compact OBS-friendly timer
- Custom background color
- Always on Top support

## Download

Download the latest Windows executable from the [Releases](../../releases) page.

No Python installation required.

## Default controls

| Key | Action |
|---|---|
| U | Finish level |
| I | Start tracking the next level |
| O | Reset timer |
| P | Exit tracker |
| F3 | Debug |

Right-click the timer to access settings and customize your hotkeys.

## Requirements

- Windows
- PAPERHEAD v49.5

## OBS

Add the tracker using Window Capture in OBS. You can change the timer's background color through Settings.

## Notes

This is an unofficial community tool. Other PAPERHEAD versions have not been tested.
